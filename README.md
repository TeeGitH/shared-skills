# shared-skills

รวม Skills สำหรับ Claude ที่ใช้ในงานจริง ส่วนใหญ่เป็นงานเอกสารภาษาไทย นำไปใช้หรือปรับต่อได้ตามสะดวก

## รายการ Skills

| Skill | ไฟล์ | ใช้ทำอะไร |
|---|---|---|
| thai-doc-layout | [thai-doc-layout.md](thai-doc-layout.md) | จัดหน้าเอกสาร Word ภาษาไทยแบบ Thai Distributed แทรกจุดตัดคำ (ZWSP) ไม่ให้คำถูกตัดครึ่งเวลาขึ้นบรรทัดใหม่ ประเมินช่องไฟ แก้ตารางล้นขอบ และเตรียมไฟล์ให้พิมพ์แก้เองได้ |

## วิธีนำไปใช้

แต่ละไฟล์คือ 1 skill มี frontmatter (`name`, `description`) อยู่บนสุด ตามด้วยคำสั่งที่ Claude ต้องทำตาม

**Claude Code**
1. สร้างโฟลเดอร์ตามชื่อ skill ใน `~/.claude/skills/` (ใช้ได้ทุกโปรเจกต์) หรือ `.claude/skills/` ของโปรเจกต์
2. คัดลอกไฟล์ไปวางในโฟลเดอร์นั้น แล้วเปลี่ยนชื่อเป็น `SKILL.md` เช่น

   ```
   ~/.claude/skills/thai-doc-layout/SKILL.md
   ```

3. เริ่ม session ใหม่ Claude จะเรียกใช้ skill เองเมื่อคำสั่งตรงกับ `description`

**Claude.ai / Claude Desktop**
1. สร้างโฟลเดอร์ชื่อ skill แล้ววางไฟล์ในชื่อ `SKILL.md` เหมือนข้างบน
2. บีบโฟลเดอร์เป็นไฟล์ `.zip` แล้วอัปโหลดในหน้า Settings → Capabilities → Skills

## ข้อกำหนดเฉพาะของแต่ละ Skill

- **thai-doc-layout**: Claude ต้องเชื่อมกับ Word ผ่าน Office.js (skill เรียกเครื่องมือ `execute_office_js`) การประเมินช่องไฟใช้ความกว้างอักษรของฟอนต์ตระกูล TH Sarabun ถ้าเอกสารใช้ฟอนต์อื่น จะแทรกจุดตัดคำได้แต่ไม่ประเมินช่องไฟ

## การเพิ่ม Skill ใหม่

1. วางไฟล์ `<ชื่อ-skill>.md` ไว้ที่ราก repo โดย `name` ใน frontmatter ต้องตรงกับชื่อไฟล์
2. เพิ่มแถวในตาราง "รายการ Skills" และถ้า skill ต้องใช้เครื่องมือหรือฟอนต์เฉพาะ ให้เพิ่มหัวข้อย่อยใน "ข้อกำหนดเฉพาะของแต่ละ Skill"
3. commit แล้ว push
